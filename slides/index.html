使用方法
点击下方任意小节卡片进入全屏可播放的幻灯片（每节 60 分钟，是否含提问/交流环节见卡片徽标）。 播放器内：← → 翻页，F 全屏， Enter 朗读/暂停，O 网格总览，Space 下一页， - / = 缩小/放大字号，0 复位， Home / End 首尾页。点击「⏺ 开始录屏」，弹窗里选「此标签页」并勾选『同时分享标签页中的音频』可录下 TTS 朗读语音（顶部会有一行共享提示条）；选「整个屏幕/窗口」画面干净但录不到 TTS，请勾选「混入麦克风」讲读。再次点击按钮下载 WebM 视频。
数据与播放器均为纯前端实现，双击打开 index.html 即可离线使用，无需服务器。
