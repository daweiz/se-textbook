# 行为统计功能 · 详细实现方案

## 0. 总体架构与数据流

```
index.html / player.html / stats.html
   │  加载 docs/js/stats.js（window.SlideStats，客户端聚合 + 静默上报）
   │  ├─ file:// 场景：Origin="null"  ──────────────┐
   │  └─ GitHub Pages (https) 场景                  │  CORS: ACAO *
   ▼                                                 ▼
POST /api/collect  (批量 JSON，fetch keepalive / sendBeacon，text/plain 或 application/json)
   ▼
docs/tools/stats-server.js  (Node 内置模块 http/fs/url，端口 3939)
   │  去重(id) → 校验(v) → JSONL 追加持久化(stats-data/events.jsonl)
   │  → 增量进内存聚合 db
   │  GET /api/stats → stats.html 渲染仪表盘
   │  GET /api/raw   → 原始事件导出
```

三条铁律贯穿全部客户端代码：
1. 任何 `window.SlideStats` 调用都必须以 `if (window.SlideStats)` 或 try/catch 包裹；
2. 统计失败只静默降级（console 最多一条 warn），绝不抛异常、绝不影响渲染/翻页/TTS；
3. 服务不可达 = 无上报 = 幻灯片照常工作。

## A. 统计服务 `docs/tools/stats-server.js`（新建）

### A.1 启动方式与配置

```
node docs/tools/stats-server.js            # 默认端口 3939，数据目录 &lt;repo&gt;/stats-data/
PORT=8080 node docs/tools/stats-server.js
DATA_DIR=/var/stats node docs/tools/stats-server.js
```

- 零 npm 依赖：仅 `require('http'/'fs'/'path'/'url')`，与本仓库 tools/ 风格一致（`'use strict'`、头部注释块、`ROOT = path.resolve(__dirname, '..', '..')`）。
- `DATA_DIR` 默认 `path.join(ROOT, 'stats-data')`。**刻意放在仓库根而非 docs/ 下**，避免与 Pages 发布目录混在一起，且被 `.gitignore` 排除（见 F）。
- 数据文件：`&lt;DATA_DIR&gt;/events.jsonl`，JSONL 追加。无文件则自动创建目录。
- 启动流程：读 env → 若 events.jsonl 存在则重放聚合 → 启动 HTTP 监听 → 打印服务地址与各端点。

### A.2 REST 端点（全部走 `sendCors()` 头）

| 方法 | 路径 | 用途 | 响应 |
|---|---|---|---|
| OPTIONS | 任意 | 预检 | 204 + CORS 头 |
| POST | `/api/collect` | 批量收集（body 为事件数组或单事件） | 204 |
| GET | `/api/stats` | 聚合报表（stats.html 消费） | 200 JSON |
| GET | `/api/raw` | 原始事件导出（`?limit=`、`?after=&lt;ts&gt;` 可选） | 200 JSON 数组 |
| GET | `/api/health` | 健康检查 | 200 `{ok:true,uptime,events,clients}` |
| GET | `/` | 极简 HTML 状态页（链接到上述端点，便于手测） | 200 text/html |

### A.4 客户端上报事件 schema（最小化，字段见 B）

每条事件统一带 `v`（schema 版本，当前 1）、`id`（客户端生成，去重用）、`ts`（epoch ms）、`localDay`、`localHour`、`tz`（分钟）。**趋势一律用客户端本地日/时**，避免服务器时区与学员时区不一致。

```jsonc
// 首页 view（index.html 每次加载发一条）
{"v":1,"id":"...","cid":"client-a1b2","type":"view","page":"home","ts":...,"localDay":"2026-09-01","localHour":9,"tz":-480}

// 播放器 view（player.html 一进入即发，即使数据加载失败也发；slug 可能为 null）
{"v":1,"id":"...","cid":"...","type":"view","page":"player","slug":"unit-01","ts":...}

// 会话 summary（进入小节成功后开始，pagehide 或主动结束时发一条，端到端只此一条主事件）
{"v":1,"id":"...","cid":"...","type":"session","sid":"s_8f3k",
 "slug":"unit-01","mode":"unit","title":"软件危机与软件工程","slides":43,
 "start":...,"end":...,"duration":210000,"fiveMin":true,
 "reachedEnd":true,"completed":true,"maxSlide":42,
 "nav":{"next":20,"prev":3,"jump":5},
 "tts":{"plays":4,"sec":900},
 "features":{"fullscreen":2,"overview":1,"theme":1,"zoom":3,"recording":0},
 "pageDwell":[[5,320000],[12,200000]],     // 稀疏：只含停留≥3s 的页 [i,ms]
 "localDay":"...","localHour":9,"tz":-480}

// 里程碑（一次性，防 pagehide 丢失导致会话指标丢）：fiveMin / endReached
{"v":1,"id":"...","cid":"...","type":"milestone","name":"fiveMin","sid":"s_8f3k","slug":"unit-01","ts":...}

// 心跳（可选，每 60s，仅作会话活跃度辅助，不做主统计）
{"v":1,"id":"...","cid":"...","type":"hb","sid":"s_8f3k","cur":12,"ts":...}
```

**服务器注意点**：
- `readBody` 后**无视 Content-Type 一律按 JSON 解析**——因为 `sendBeacon` 默认发 `text/plain;charset=UTF-8`，`fetch` 发 `application/json`，两路都要能收。
- `ingestEvent` 先查 `seen` 去重（fetch 超时重试/beacon 与 fetch 双发可能重复），再聚合，再 `appendFileSync` 落盘；落盘失败只 `console.warn` 不中断（内存聚合已更新）。
- 重放时坏行跳过并 `badLines++`，绝不 crash。

### A.5 CORS 要点

- 所有响应（含 204）都带 `Access-Control-Allow-Origin: *` —— 同时放行 file:// 的 `Origin: null` 与 https 源。
- OPTIONS 预检：`Access-Control-Allow-Methods: POST, GET, OPTIONS`，`Access-Control-Allow-Headers: Content-Type`，`Max-Age: 86400`。**漏掉 OPTIONS 处理是 file:// 下最典型的踩坑**（浏览器对跨源 `application/json` 的 POST 必先预检）。
- sendBeacon 走 `text/plain`（CORS-safelisted，无预检），所以 unload 瞬间上报也能发出。

## B. 客户端采集器 `docs/js/stats.js`（新建）

零依赖 IIFE，暴露 `window.SlideStats`。index.html / player.html / stats.html 共用；stats.html 通过 `window.SLIDE_STATS_NO_AUTO = true` 关闭自动跟踪（只复用端点解析与 fetch 辅助）。

### B.1 端点配置优先级

```js
// inline window.SLIDE_STATS_ENDPOINT → localStorage 'slides-stats-endpoint' → 默认 http://localhost:3939
// 空串 / 'off' / 'false' → 禁用（isEnabled() 为 false，一切静默）
```

- 部署到 GitHub Pages 时，在 stats.js 之前用内联 `&lt;script&gt;window.SLIDE_STATS_ENDPOINT="https://…";&lt;/script&gt;` 覆盖为 https 端点（见 G 混合内容说明）。
- 讲师本地可 `setEndpoint('http://127.0.0.1:3939')` 存 localStorage 覆盖，无需改文件。

### B.2 对外 API

```js
window.SlideStats = {
  pageview(page, extra),        // 'home' | 'player'，入队 view 事件
  startSession(info),           // {slug, mode, slides, title, unit, minutes}；若已有活动会话先 endSession()
  setSlide(i, total),           // 关闭上一页 dwell，设置当前页；i===total-1 时标记 reachedEnd 并记录 endEnteredAt
  trackNav(dir),                // 'next' | 'prev' | 'jump'
  trackTTS(kind),               // 'play' | 'start' | 'stop'（见 C 插桩顺序）
  trackFeature(name),           // 'fullscreen' | 'overview' | 'theme' | 'zoom' | 'recording'
  milestone(name),              // 'fiveMin' | 'endReached'（一次性入队并立即 flush）
  endSession(),                 // 结算 dwell/tts/duration/completed → 入队 session → 立即 flush
  isEnabled(), getEndpoint(), setEndpoint(url),
  fetchStats(url),              // 供 stats.html 复用：GET /api/stats，超时/失败返回 null
};
```

### B.3 会话模型与本地聚合（模块内）

```js
const session = {
  sid: genId(), cid, slug: null, mode: null, slides: 0,
  start: 0, cur: 0, maxSlide: 0, slideStartTs: 0,
  reachedEnd: false, endEnteredAt: 0,
  nav: { next: 0, prev: 0, jump: 0 },
  tts: { plays: 0, sec: 0, activeSince: 0 },   // activeSince 记录当前朗读段起点
  features: { fullscreen: 0, overview: 0, theme: 0, zoom: 0, recording: 0 },
  dwell: new Map(),                             // slideIndex -&gt; 累计 ms
  _done: false,
};
```

- **dwell**：`setSlide(i)` 先结算 `session.dwell.set(prev, +now-slideStartTs)`，再 `cur=i; slideStartTs=now`。`endSession()` 再补结当前页。初始页由 `startSession` 置 `cur=0; slideStartTs=now`（不重复结算）。
- **TTS 时长**：`trackTTS('start')` 记 `activeSince=now`；`trackTTS('stop')` 若 `activeSince` 非零则累加 `sec+=(now-activeSince)/1000` 并清零。**幂等**（stop 时未 active 为 no-op），天然防 cancel 时 onend 双触发。
- **completion**：`endSession()` 时若 `reachedEnd &amp;&amp; now - endEnteredAt &gt;= 30000` → `completed=true`。
- **fiveMin**：`endSession()` 时 `duration &gt;= 300000` → `fiveMin=true`；另外每 60s 心跳 tick 里检查一次，首次越线即发 `milestone('fiveMin')` 并立即 flush——**pagehide 丢失也能保住 5 分钟指标**。

### B.4 发送缓冲与离线韧性

- **队列 + 节流**：`queue` 累积事件；`setInterval(flush, 30000)` 且 `queue.length&gt;=20` 时即时 flush。
- **flush 优先级**：
  1. `navigator.sendBeacon(url, new Blob([JSON.stringify(batch)], {type:'text/plain'}))`（unload 可靠、无预检）；
  2. 兜底 `fetch(url, {method:'POST', keepalive:true, headers:{'Content-Type':'text/plain'}, body:JSON.stringify(batch)})`（keepalive 保证 unload 期完成；text/plain 免预检）；
  3. 都失败 → 存 localStorage `slides-stats-queue`（上限 50 条 / 20KB，超限丢最旧），下次 flush 或下次页面加载时重试。
- **生命期钩子**（stats.js 自注册，播放器无需操心）：
  - `pagehide` → `endSession()` + `flush()`（会话终结与发送）。
  - `visibilitychange→hidden` → **只 flush 队列、不 endSession**（切标签 ≠ 离开）。
  - `beforeunload` 仅作 sendBeacon 可用性探测，不做业务（不在这里发请求，避免与 pagehide 竞争）。
- **绝不抛异常**：每个公开方法 try/catch；`localStorage` 全部 try/catch（沿袭 player.js `slides-zoom` 的既有先例）；禁用态下所有方法立即 return。
- **cid**：localStorage `slides-stats-cid` 持久化客户端 id，供“独立访客”去重。

### B.5 加载顺序（重要）

stats.js 必须在 player.js **之前**加载，因为 player.js 启动段（`params()` 之后约 539 行）就要调用 `SlideStats.pageview`。三处插入位置见 C/D。

```js
function go(i) {
  if (!CHAPTER) return;
  i = Math.max(0, Math.min(CHAPTER.slides.length - 1, i));
  if (i === CUR) return;                    // 不变：先退出，杜绝 no-op 计数
  const from = CUR;
  CUR = i;
  render();
  if (window.SlideStats) {
    SlideStats.trackNav(i === from + 1 ? "next" : i === from - 1 ? "prev" : "jump");
    SlideStats.setSlide(i, CHAPTER.slides.length);
  }
}
```

方向识别：`next`（含 TTS 自动下一页、舞台点击右半、→/Space）、`prev`、其余（圆点/总览卡/进度条/Home/End/舞台点击左半）→ `jump`。TTS 自动翻页走 `next()`→`go()`，自动计为 next——符合真实行为。

## G. 验证方案

### G.1 本地端到端（file:// 场景）

### G.2 韧性验证

- 不启动服务直接开播放器：翻页/TTS/缩放/全屏全部正常，Console 无报错（至多一条 warn）。
- 中途杀掉服务：会话继续，`pagehide` 时 sendBeacon 失败 → 事件进 localStorage 队列；重启服务后再开页面应重试补发。

### G.3 部署（GitHub Pages）注意事项

- **混合内容是真雷区**：https 页面 `fetch` 到 http 服务会被浏览器直接拦截。GitHub Pages 场景统计服务必须 https（如内网/云主机 + Caddy/nginx 反代，或 Cloudflare Tunnel 自带证书）。
- 部署时在三个 HTML 里于 stats.js 之前加内联 `&lt;script&gt;window.SLIDE_STATS_ENDPOINT="https://&lt;你的域名&gt;:3939";&lt;/script&gt;`；`*` CORS 头已覆盖 Pages 域名与 file:// 的 `null` Origin，无需按域名白名单。
- 本地/LAN/纯 http 场景不受此限（http→http、file://→http://localhost 均可用；Chrome 将 `localhost` 视为安全上下文，无混合内容报错）。

## 最容易出错的地方与规避办法（汇总）

1. **OPTIONS 预检**：跨源 `application/json` POST 必先预检，服务端漏处理 = file:// 与 Pages 双失败。规避：路由统一先 `if (req.method==='OPTIONS') handlePreflight`；所有响应带 `ACAO: *`。
2. **sendBeacon 的 Content-Type**：beacon 默认 `text/plain`。服务端**忽略 Content-Type 一律 JSON.parse**，并优先用 `text/plain` Blob 走 beacon 免预检——两者都满足。
3. **beforeunload/pagehide 时机**：不要在 `beforeunload` 里发 fetch（不可靠）；用 `pagehide` 终结会话 + `sendBeacon`（keepalive 语义、不受 unload 取消）；`visibilitychange→hidden` 只 flush 队列不 endSession（切标签 ≠ 离开）。
4. **会话丢失**：强杀标签/崩溃时 pagehide 不触发 → summary 丢。规避：`fiveMin`/`endReached` 里程碑即时单发 + localStorage 小队列重试；对“完播”30s dwell 依赖 pagehide，接受少量丢失并如实说明。
5. **事件 schema 变更兼容**：每条事件带 `v`；服务端 `aggregateEvent` 按 `type` 分发、未知 type 静默忽略、可选字段取默认值；JSONL 重放坏行跳过计数；`/api/raw` 保留原始事件便于查证。新增字段不破坏旧服务，老数据重放不被新服务拒绝。
6. **go() 早退与 render 复用**：在 `i===CUR` 早退**之后**插桩，否则翻页 no-op 被计数；初始页 dwell 基线由 `startSession` 建立，不在 `initPlayer` 里再 `setSlide`。
7. **TTS 计时泄漏**：render() 自动翻页 `stopTTS(true)` 取消朗读时 `onerror('interrupted')` 被现有代码忽略 → 计时器不停。规避：`stopTTS` 内（无论 silent）都 `trackTTS('stop')` 且幂等。
8. **缩放初始化假计数**：`applyZoom` 被 `initZoom` 调用 → 在 `setZoom` 与 `case "0"` 处计数，绝不在 `applyZoom`/`initZoom` 计。
9. **混合内容**（见 G.3）：https 页面上报 http 端点必被拦，部署必须给统计服务上 https。
10. **localStorage 在 file:// 的可用性**：Chrome/Edge 可用（player.js 已有 `slides-zoom` 先例），但隐私模式等仍可能抛异常——全部 try/catch，绝不外抛。
